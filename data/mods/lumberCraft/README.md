# Lumber Craft

Tools and muskets also consume **lumber**, so lumberjacks stay useful after the colony is built.

| Building | Recipe |
|----------|--------|
| Blacksmith house / shop / iron works | ore + lumber → tools |
| Armory / magazine / arsenal | tools + lumber → muskets |

Ratios stay light (1–3 lumber per tick) so ore and tools remain the main bottleneck.

## Enable

Preferences → Mods → enable **Lumber Craft**, then start a **new game**.

If you also use **Basic Buildings**, enable Lumber Craft **after** it so the lumber inputs are not overwritten.

Or use `./bin/run-mods.sh`.
