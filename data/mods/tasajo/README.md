# Tasajo

Adds a salt-meat export chain inspired by FreeCol 2 forum ideas
([Salt Meat](https://sourceforge.net/p/freecol/discussion/719665/thread/aa604df1de/), Misiulo):

| Step | What |
|------|------|
| Hunt | **Meat** on any forest (bonus from **Game** / deer). Warehouse raw — **not** eaten |
| Mine | **Salt** on hills, mountains, and desert (bonus from **Salt** deposits / flats) |
| Process | **Salting house** (32 hammers) → **Salting works** → **Packing house** (Adam Smith) |
|         | meat + salt → salt meat (3+3→3 / 6+6→6 / 6+6→9) |
| Export | **Salt meat / Tasajo** to Europe (not edible) |
| Food | Colonists still eat **grain / fish** as usual |
| Experts | **Expert Hunter**, **Expert Salt Miner**, **Expert Meat Salter** |

## Enable

Preferences → Mods → enable **Tasajo**, then start a new game.

Works with **Deeper Buildings**, **Libertadores**, and **Basic Buildings**
(salting house costs 32 hammers, same as other workshops).

## Native experts

With the **Conversos** mod and Bartolome de las Casas in the Congress,
converts can become **Native Expert Hunters** (meat) and **Native Expert
Salt Miners**.

## Art

Custom isometric icons for buildings; salt goods/bonus and unit art generated
to match FreeCol sprite style.
