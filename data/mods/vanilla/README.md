# Vanilla

**Vanilla** is a scarce New World luxury. Harvest it on tropical tiles and
**export it raw** — same idea as silver, no workshop chain.

| | |
|--|--|
| Tiles | Tropical forest (best), rain forest, savannah, scrub forest |
| Bonus | **Vanilla orchid** resource (×2) |
| Expert | Expert Vanilla Planter |
| Market | High Europe price (~silver tier); price falls if you flood the market |

Aztec and Arawak settlements may teach vanilla planting.

## Native experts

With the **Conversos** mod and Bartolome de las Casas in the Congress,
converts working vanilla can become **Native Vanilla Planters**.

## Enable

Preferences → Mods → enable **Vanilla**, then start a **new game**.

Or use `./bin/run-mods.sh`.
